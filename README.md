# Micro Splash 🐋🌊

Um jogo 2D de plataforma/navegação subaquática desenvolvido em TypeScript com **Kaboom.js** e **Vite**.

## 🛠️ Stack Tecnológica

- **Linguagem:** TypeScript
- **Engine 2D:** Kaboom.js
- **Build Tool:** Vite
- **Containerização:** Docker / Docker Compose

---

## 🚀 Como Executar

### Opção 1: Sem Docker (Node.js local)

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev
```

Acesse em: `http://localhost:5173`

---

### Opção 2: Com Docker

```bash
# Iniciar o ambiente via Docker Compose
docker compose up
```

Acesse em: `http://localhost:5173`

---

## 🎮 Controles

- `Espaço`: Nadar / Impulso para cima
- `Seta Direita`: Avançar
- `Seta Esquerda`: Recuar
